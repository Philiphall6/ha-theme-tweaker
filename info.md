# HA Theme Tweaker

HA Theme Tweaker adds a Home Assistant sidebar panel for persistent visual CSS overrides on top of the currently active theme.

It is designed for users who want to tweak sidebar badges, general colors, cards, optional Mushroom styles, and header colors without editing the original theme YAML.

Values left empty are stored as `null`, so Home Assistant keeps inheriting the active theme value. Color controls include opacity, the preview can be clicked to jump to the related setting, and overrides can be scoped to web, mobile, or both.
